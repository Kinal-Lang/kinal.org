什么是 Kinal？

Kinal 是一门开源的静态类型编程语言，可用于应用和系统开发。它支持 LLVM 原生编译和 KinalVM 字节码执行，并提供 C 互操作接口。

基本语法

源文件使用 .kn 扩展名。Unit 声明模块，Get 引入依赖。下面的程序会向控制台输出一行文本。

hello.kn
Unit App;

Get IO.Console;

Static Function int Main()
{
    IO.Console.PrintLine("Hello, World!");
    Return 0;
}
Hello World 教程→

编译与运行

LLVM 后端生成原生可执行文件。KinalVM 后端生成 KNC 字节码，再交给虚拟机解释执行。

编译并运行原生程序
kinal run hello.kn
通过 KinalVM 运行
kinal vm run hello.kn

两种后端的功能支持并不完全一致，使用前请查阅后端支持表。

C 互操作

通过 Extern 声明 C 函数，用 Delegate 描述函数指针。调用方需要遵守外部库的 ABI、参数类型和内存管理约定。
