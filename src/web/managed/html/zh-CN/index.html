Kinal 编程语言

一门开源的静态类型语言。支持 LLVM 原生编译、KinalVM 字节码执行和 C 互操作。Kinal 1.0 已完成编译器自举。

    为什么选择 Kinal
    
          
    
            用类和接口组织应用，用原生接口连接已有的代码。两种工作，可以在同一个项目里完成。
          
    
          了解设计取舍→
        
    
        
    
          
    
            
    熟悉的写法，明确的结构
    
            
    
              静态类型、类、接口和属性，让数据与行为有清楚的边界。用
              Unit 和
              Get 组织模块，随着项目增长拆分代码。
            
    
            看看语言怎么写→

              Delegate
              传递回调。接入系统接口或现有库时，直接描述需要的原生边界。
