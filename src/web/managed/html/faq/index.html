Getting started

What is Kinal?

Kinal is an open-source, statically typed general-purpose language. It supports native compilation with LLVM and bytecode execution with KinalVM.

Is Kinal open source?

Yes. Kinal is developed openly on GitHub at Kinal-Lang/Kinal. Contributions are welcome.

Can I try Kinal without installing anything?

Yes. Edit an example in the Playground and select Run to see the result.

What is the learning curve like?

If you have used C#, Java or another C-family language, Kinal’s functions and control flow should look familiar. Start with the Hello World tutorial.

Is there IDE support?

The Kinal VS Code extension provides highlighting, LSP diagnostics, completion, definition navigation, formatting, run and project-creation commands. Install the full toolchain and configure compiler/LSP paths; the nearest kinal.knproj defines project scope.

Platforms and interop

What platforms does Kinal support?

Native targets include x64/ARM64 Windows, Linux and macOS, plus Windows x86 and supported freestanding targets. The 1.0 release provides SDKs for Windows, Linux and macOS on x64 and ARM64. On Windows, IO.UI 2.0 draws its controls on a shared Direct3D 11 surface.

Can I call C libraries from Kinal?

Yes. Use Extern for functions and Delegate for function-pointer signatures. Match the native ABI, calling convention, C integer widths and pointer lifetimes. Arbitrary C calls are not a general VM capability.

Do Native and VM support the same features?

Support varies by backend. Native supports direct C ABI calls. KinalVM provides its own set of host operations, and features such as general Await have separate limits. Consult the backend support table for specific APIs.

How does Kinal mark unsafe operations?

Kinal uses Safe, Trusted, and Unsafe to express where operations are allowed. See Kinal’s safety design and Memory and Lifetimes for the applicable rules.

Does Kinal support object-oriented native programs?

Kinal offers familiar class, interface and property syntax. It can compile through LLVM and exposes the C ABI directly for native interop.

Toolchain and releases

Can I copy just the compiler executable?

Keep the complete distribution: LLVM, linker, runtime, standard packages and LSP. Built native and packed VM programs can also depend on system or package shared libraries.

How do I manage multiple source files?

Use kinal.knproj SourceSets and Profiles with FileOnly, EntryUnit, ReachableUnits or AllSources. Get controls visibility and does not expand the active source-set boundary.

What if documentation differs from my release?

Check kinal --version and kinalvm --version, then compare the installed SDK with its release notes. The tool versions and KNC file format version are tracked separately.

Is the Kinal compiler self-hosted?

Yes. Kinal 1.0.0 is the first release to ship a compiler written in Kinal and built by Kinal. The 0.10.0 C compiler seeded the bootstrap, and the final two compiler builds matched byte for byte on Windows, Linux and macOS, on both x64 and ARM64.
