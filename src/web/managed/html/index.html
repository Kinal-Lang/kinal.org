    Why choose Kinal
    
          
    
            Build your application with classes and interfaces. Connect it to
            existing native code. Keep both in the same project.
          
    
          The design decisions→
        
    
        
    
          
    
            
    Familiar ways to structure code
    
            
    
              Static types, classes, interfaces, and properties make data and
              behavior explicit. Use Unit and Get to
              split your code into modules as the project grows.
            
    
            Explore the language→
          
    
          
    
            
    Keep using your C libraries
    
            
    
              Declare external functions with Extern and pass
              callbacks with Delegate. Describe the native boundary
              directly when working with system APIs or existing libraries.
            
    
            Native interoperability→
          
    
          
    
            
    Choose how your program runs
    
            
    
              Compile through LLVM for a native program, or use KinalVM for
              bytecode execution. Check the documented capabilities and limits
              of each backend against your project's needs.
